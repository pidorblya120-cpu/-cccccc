ИНВЕНТАРИЗАЦИЯ КМК — ЛОКАЛЬНАЯ ВЕРСИЯ PHP + MYSQL

ТРЕБОВАНИЯ
- Windows 10/11
- XAMPP (Apache, PHP 8+, MySQL/MariaDB)
- Современный браузер

УСТАНОВКА
1. Установите и запустите XAMPP.
2. Скопируйте папку kmk_inventory в C:\xampp\htdocs\
3. Откройте XAMPP Control Panel и нажмите Start напротив Apache и MySQL.
4. Откройте в браузере http://localhost/phpmyadmin (убедитесь, что MySQL запущен).
5. Откройте http://localhost/kmk_inventory/install.php
6. Дождитесь сообщения об успешной установке.
7. Нажмите «Перейти ко входу».

После успешной установки удалите файл install.php.

НАСТРОЙКА MYSQL
По умолчанию XAMPP использует:
DB_HOST=127.0.0.1, DB_NAME=kmk_inventory, DB_USER=root, DB_PASS=''
Если у вас другой пароль MySQL, измените DB_PASS в config.php.

ДОСТУП КАБИНЕТОВ
1. Администратор открывает раздел «Ключи кабинетов».
2. Напротив нужного помещения нажимает «Создать / сменить ключ».
3. Скопируйте показанный ключ и передайте ответственному сотруднику кабинета.
4. Сотрудник открывает http://localhost/kmk_inventory/index.php?page=room_access&mode=login, выбирает кабинет и вводит ключ.
5. В кабинетном режиме сотрудник может добавлять оборудование только в свой кабинет. Для изменения и перемещения записей обращается к администратору.

ВОЗМОЖНОСТИ
- Учебные годы и выбор активного года
- Разделы помещений и добавление пользовательских категорий
- Добавление помещений
- Учёт оборудования: номер, наименование, количество, инвентарный номер, примечание, статус
- Редактирование и удаление оборудования
- Перемещение оборудования с датой, направлением и причиной
- История перемещений
- Поиск по наименованию и инвентарному номеру
- Экспорт ведомости в CSV, который открывается в Excel
- Смена пароля администратора
- Индивидуальные ключи доступа для каждого кабинета (ключи хранятся в базе в виде хеша)
- Отдельный режим кабинета: сотрудник может добавлять оборудование только в свой кабинет
- Интерфейс на русском и казахском языках
- Официальный логотип колледжа в интерфейсе

ВАЖНО
Это локальная установка на одном компьютере. Данные хранятся в MySQL на этом компьютере.
Делайте резервную копию базы через phpMyAdmin: выбрать kmk_inventory → Экспорт.
